# 可解释知识图谱补全与审核工作台

## 项目背景

本项目基于已经完成的知识图谱算法研究，探索将算法结果转化为可供审核人员使用的前后端产品。

## 我的角色

产品经理，主要负责项目初期的需求分析、MVP规划、原型设计、测试方案和PRD整理。

## 我完成的工作

- 梳理产品定位、目标用户和需求假设
- 规划MVP功能范围
- 设计候选结果、评分、路径和人工审核流程
- 制作可交互HTML原型
- 筛选并接入21条测试案例
- 设计测试题库、测试方案和记录表
- 基于模拟数据预判交互风险
- 输出阶段性PRD

## 项目当前阶段

当前处于前期产品设计和原型验证阶段，尚未完成正式前后端开发，也尚未开展正式真人用户测试。
